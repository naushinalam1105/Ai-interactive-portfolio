A full-stack, conversational personal portfolio that lets recruiters and visitors interactively explore candidate experience, technical stack, projects, and credentials through a neural chat interface.

Architecture: Decoupled client-server design using pure Vanilla HTML5, CSS3, and JavaScript on the frontend with a high-performance Python FastAPI backend.

Inference Engine: Powered by Groq Cloud LPUs utilizing llama-3.3-70b-versatile for sub-second, context-grounded conversational responses.

Context Grounding: Leverages strict system guardrails, semantic synonym mapping, and structured Pydantic schema validation to prevent hallucinations and maintain factual accuracy.

UI & Performance: Zero framework bloat—instant load times, responsive custom dark aesthetic, dynamic DOM manipulation, and integrated Markdown parsing via Marked.js.
